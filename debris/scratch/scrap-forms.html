Salvage Forms

The Scrap pickup's hitbox just doubled, and at the new size its tetromino silhouette reads less like salvage and more like a falling block from a different game. Five replacement forms below, each rendered live at the new footprint and judged against the same brief the rest of Debris already follows: flat fills, a thin stroke, one accent hue, no shape anyone could mistake for a rock, a Shield, or a boss part.

Two more, in a different register

unfilled wireframe, not flat fill

These two break from the flat-fill convention the other five (and every other pickup in the game) use, and that's deliberate: an unfilled vector outline is exactly how the original 1979 Asteroids ship itself was drawn, before this codebase's own ships ever got a fill color. Worth weighing as its own axis — literal 3D wireframe debris vs. the flat-shaded language everything else in Debris already speaks.

dashed ring = small asteroid, 16px

Shattered Core

A hollow cube, drawn as an open wireframe rather than a filled solid — no faces, just the twelve edges, tumbling freely in true 3D. Reads as the structural skeleton of a dead satellite, not a rock, on silhouette alone.

Cargo Crate

An elongated wireframe prism, plain edges only — no cross-bracing, just the box itself tumbling in true 3D. Reads as a modular cargo module by proportion alone (long and rectangular, unlike anything else in the set) rather than leaning on an arcade container icon to make the point.

Every render above uses only the game's existing Scrap hue (#4fae82). The first five keep the flat-fill-plus-stroke convention every other entity in Debris already draws with; Shattered Core and Cargo Crate deliberately switch to unfilled wireframe instead, so they read as a genuine alternative visual language rather than two more shapes in the same set.
