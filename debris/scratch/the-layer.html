Saboteur, Option 1 — Mechanism Variants

The Layer

Three ways the same idea could actually work: a hull that visibly carries a limited number of mines and releases them as it drifts, so a player can glance at it and tell roughly how many more it has left to drop. All three reuse the mine's own metal-and-red-core language - this is meant to read as kin to what it deploys, not an unrelated machine that happens to drop the same hazard.

Mechanism A

Rack-Belly

A slab hull with four mine-nodes clipped underneath in a row, like an open bomb bay. Each drop empties one socket outright - the most literal "ammo count," readable even at a glance.

Read — clearest Reference — bomb-bay rack Cost — cheapest to build

Mechanism B

Carousel

Mine-nodes ride a slow-rotating ring around the hull, like a revolver cylinder. The node currently at the bottom "gate" releases when it's ready - more spectacle, same information.

Read — good, once learned Reference — revolver cylinder Cost — more animation work

Mechanism C

Towline

Mines ride a trailing tether like beads, feeding outward and releasing at the far end while new ones form near the hull - a real minelaying-ship silhouette, continuous rather than discrete.

Read — most atmospheric Reference — minelayer ship Cost — trickiest to tune
Hull plating and the mine-nodes both reuse the same tones the actual Drift Mine mockup already established - gunmetal (#3c4560 / #14141c) for structure, COLORS.ufo red for every core light. Nothing new introduced; the family resemblance is the entire point.
